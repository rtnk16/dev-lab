# dev-lab

Personal workspace for learning, experimentation, and development.

## Directory Structure

```text
dev-lab/
├── learning/
│   ├── programming/
│   │   ├── c/
│   │   ├── cpp/
│   │   └── python/
│   ├── linux/
│   ├── embedded/
│   ├── ai/
│   └── robotics/
├── experiments/
│   ├── benchmarks/
│   ├── poc/
│   └── sandbox/
├── projects/
│   ├── tools/
│   ├── applications/
│   └── agents/
├── notes/
│   ├── concepts/
│   └── troubleshooting/
├── scripts/
├── .gitignore
└── README.md
```

| Directory | Purpose |
| --- | --- |
| `learning/` | Study materials, exercises, and examples organized by topic |
| `experiments/benchmarks/` | Performance measurements and comparisons |
| `experiments/poc/` | Proofs of concept to evaluate ideas and technologies |
| `experiments/sandbox/` | Exploratory experiments |
| `projects/tools/` | Reusable utilities |
| `projects/applications/` | Application projects |
| `projects/agents/` | AI agent projects |
| `notes/concepts/` | Explanations and summaries of concepts |
| `notes/troubleshooting/` | Problems, investigations, and solutions |
| `scripts/` | Repository maintenance and automation scripts |

Empty directories contain `.gitkeep` placeholders so Git can track the structure.
Remove a placeholder when adding content to its directory.
Keep setup instructions and validation commands alongside each project or experiment.
