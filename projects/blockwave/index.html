HOW TO PLAY

揃えて、消して、
自分のペースで。

落ちてくるブロックを動かして、横一列を隙間なく埋めましょう。10ライン消すたびにレベルが上がり、落下が速くなります。

← → / A D
左右に移動
↑ / X ・ Z
右回転 ・ 左回転
↓ / S ・ Space
ゆっくり落下 ・ 一気に落下
C ・ P / Esc
ホールド ・ 一時停止
Enter ・ R
開始 / 再開 ・ リスタート

ホールドはブロックを固定するまで1回。着地点ガイドは盤面下のスイッチで切り替えられます。スマートフォンでは画面下のボタンで操作できます。
PLAY IT YOUR WAY

ブラウザから、
ターミナルへ。

GitHubからリポジトリのZIPをダウンロードして展開し、projects/blockwave で実行してください。Node.js 22.12以降が必要です。

# 初回だけ
npm ci

# ターミナルで遊ぶ
npm run play

# ブラウザで遊ぶ
npm run dev

どちらも同じTypeScriptのゲームロジックを使用。テストと日本語READMEも同梱しています。
