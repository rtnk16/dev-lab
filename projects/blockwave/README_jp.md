# BLOCKWAVE

[English](README.md) · [リポジトリ](../../README_jp.md)

- Webブラウザと対話型ターミナルの両方で遊べるTypeScriptのテトリスゲームです。
- 移動、回転、落下、ホールド、ライン消去、スコア計算には、両方のクライアントで同じゲームエンジンを使います。
- ブラウザ版の画面は日本語で、キーボードとタッチ操作に対応しています。

## 必要なもの

- Node.js 22.12以降とnpm。
- ターミナル版は、ANSIカラーに対応した56列×26行以上の対話型ターミナル。

## セットアップと起動

初めて取得する場合は、リポジトリをcloneしてからプロジェクトの依存関係をインストールします。

```sh
git clone https://github.com/rtnk16/dev-lab.git
cd dev-lab/projects/blockwave
npm ci
```

取得済みの場合は、リポジトリのルートを開き、`cd projects/blockwave` と `npm ci` を実行してください。ZIPをダウンロードした場合は、展開して `dev-lab-main` を開いてから、同じコマンドを実行します。ブラウザ画面のソースダウンロードボタンでは、このプロジェクトを含むリポジトリ全体のZIPを取得できます。

ブラウザ版を起動します。

```sh
npm run dev
```

Viteが表示したURLをブラウザで開き、開始ボタンを押すか `Enter` を押してください。

ターミナル版を起動します。

```sh
npm run play
```

ターミナル内にゲームが表示されます。`Enter` で開始し、`Q` で終了します。ターミナル版は起動前に自動でコンパイルされます。

## 操作とルール

| キー | 操作 |
| --- | --- |
| ← / A、→ / D | 左右に移動 |
| ↓ / S | ソフトドロップ |
| ↑ / X | 右回転 |
| Z | 左回転 |
| Space | ハードドロップ |
| C | ホールド |
| P / Esc | 一時停止・再開 |
| Enter | 開始・再開・ゲームオーバー後の再挑戦 |
| R | 最初からやり直す |
| Q / Ctrl+C | ターミナル版を終了 |

- 横一列を隙間なく埋めると消えます。複数の行を同時に消すと、より多くのスコアを獲得できます。
- 10ライン消すごとにレベルと落下速度が上がります。
- ホールドは、操作中のブロックが固定されるまで1回だけ使えます。
- ブロックは7種類を1組にしてシャッフルするため、各組にはそれぞれの形が1回ずつ含まれます。
- 着地点ガイドは、操作中のブロックがどこに落ちるかを示します。ホールドと次のブロックの表示を使って、先の配置を考えられます。

### ブラウザ版

- スマートフォンでは画面内のボタンで操作できます。
- 遊び方ダイアログで操作を確認でき、ターミナルのダイアログからは起動手順とリポジトリのZIPを開けます。
- サウンドと着地点ガイドは切り替えられます。設定とベストスコアは、そのブラウザの `localStorage` に保存します。
- タブを切り替えたり、ウィンドウからフォーカスを移したりすると、自動で一時停止します。

### ターミナル版

- 表示領域が56列×26行未満になると進行を止め、十分な大きさに戻ると続行します。
- 終了時にはターミナルのカーソル、画面、入力モードを復元します。
- ベストスコアは現在のプロセスの実行中のみ保持します。`NO_COLOR=1` を設定すると、ブロックのANSIカラーを無効にできます。

## ビルドと検証

`projects/blockwave` で次のコマンドを実行します。

```sh
npm run typecheck
npm test
npm run build
```

- `typecheck` は、ファイルを生成せずにTypeScriptの型を検査します。
- `test` は、ブロックの配布、衝突、回転、ホールド、ライン消去、スコア、時間経過、一時停止、ゲームオーバーを対象に、エンジンのテストをコンパイルして実行します。
- `build` は、ブラウザ版を `dist/`、ターミナル版を `build/` に出力します。
- `npm run preview` は、ブラウザ版のビルドをローカルで配信します。
- 生成ファイル、テストの出力、依存関係のキャッシュはGitの管理対象から除外します。

ビルド後は、対話入力なしで次のコマンドも実行できます。

```sh
node build/terminal/index.js --help
node build/terminal/index.js --snapshot
```

`--help` は日本語の操作説明と必要環境を表示します。`--snapshot` は同じ内容を再現できる盤面のプレビューを表示して終了します。

## 困ったとき

- インストール時にNode.jsのバージョンが対応外と表示された場合は、`node --version` で確認し、Node.js 22.12以降をインストールしてから `npm ci` を再実行してください。
- コマンドは `projects/blockwave` で実行します。ターミナル版の起動は `npm run play` です。ゲームを始めずに操作説明を見る場合は、`npm run play -- --help` を使います。

## 構成

```text
projects/blockwave/
├── src/
│   ├── core/game.ts       DOMやNode.js APIに依存しない共通ゲームルール
│   ├── web/               ブラウザの描画、入力、スタイル
│   └── terminal/index.ts  ターミナルの描画と入力
├── tests/game.test.ts     エンジンのテスト
├── public/               静的アセット
├── index.html            ブラウザの画面
├── package.json          コマンドと依存関係
├── package-lock.json     固定した依存関係のバージョン
├── README.md
└── README_jp.md
```

各クライアントは入力をエンジンの操作に変換し、結果の状態を描画します。エンジンには乱数生成関数を渡せるため、テストでは特定のブロック順を再現できます。
