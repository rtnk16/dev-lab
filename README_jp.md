# dev-lab

学習、実験、開発のための個人用ワークスペースです。

[English](README.md)

## ディレクトリ構成

```text
dev-lab/
├── .github/
│   ├── copilot-instructions.md
│   └── copilot-instructions_jp.md
├── learning/
│   └── ai/
│       ├── AI_GUIDE.md
│       └── AI_GUIDE_jp.md
├── .gitignore
├── AGENTS.md
├── AGENTS_jp.md
├── README.md
└── README_jp.md
```

ディレクトリは、内容を追加するときにのみ作成します。空ディレクトリを維持するためのプレースホルダーは追加しません。
学習資料は `learning/` 配下にトピック別に整理します。必要に応じて `experiments/`、`projects/`、
`notes/`、`scripts/` を追加し、各プロジェクトや実験の近くにセットアップ手順と検証コマンドを記載します。
